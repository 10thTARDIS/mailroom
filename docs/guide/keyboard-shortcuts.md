# Keyboard shortcuts

Every shortcut Mailroom has. Press `?` in the app to see the same list.

Keys work when you are not typing in a box. `Ctrl/⌘` means Ctrl on Windows and Linux, and ⌘ on a Mac. The app lists these in a single flat list; the groups below are for reading only.

## Moving around

| Keys | Does |
|---|---|
| `j` / `k` / `↑` / `↓` | Next / previous message |
| `Home` / `End` | First / last message in the list |
| `PageUp` / `PageDown` | A screenful of messages at a time |
| `Enter` / `o` | Open the selected message |
| `u` / `Esc` | Back to the list |
| `g` then `i` / `p` / `n` / `s` / `b` / `e` / `d` / `t` / `a` | Go to inbox / priority / needs a category / starred / snoozed / sent / drafts / trash / archive |
| `g` then `g` | Open the account switcher |
| `g` then `0`–`9` | Show all accounts / only the Nth account |
| `/` | Search |
| `Ctrl/⌘+K` | Command palette |
| `?` | This help |

## Acting on mail

| Keys | Does |
|---|---|
| `e` | Archive |
| `#` | Delete |
| `s` | Toggle star (the in-tray flag, on the desk and in-tray lists) |
| `p` | Toggle pin |
| `b` | Snooze (in the Snoozed view: bring it back) |
| `!` | Correct the priority verdict (important / not important) |
| `m` | Mute / unmute the conversation |
| `Shift+I` / `Shift+U` | Mark read / mark unread |
| `l` | Label |
| `l` then `1`–`9` | Apply one of the first nine labels without leaving the keyboard |
| `-` | Does not need a category (in the **Needs a category** view) |
| `Ctrl/⌘+Z` | Undo the last thing you did |
| `g` then `u` | Move to the Undo button (the countdown pauses there) |

## Selecting

| Keys | Does |
|---|---|
| `x` / `Space` | Toggle selection (Space: the desk and in-tray lists only) |
| `Shift`+click | Select a range |
| `Ctrl/⌘`+click | Add or remove one message from the selection (the desk and in-tray lists) |

## Writing

| Keys | Does |
|---|---|
| `c` | Compose |
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `Ctrl/⌘+Enter` | Send the message you are composing |
| `Ctrl/⌘+Shift+Enter` | Send & archive the conversation you are replying to or forwarding |

## On the desk

| Keys | Does |
|---|---|
| `1`–`9` | Re-file into the Nth area (in Needs sorting: place it there) |
| `Shift+↑` | Move above the line: this belongs on the surface |
| `Shift+↓` | Move below the line: this belongs in the drawer |
| `←` / `→` | Switch between Review first and Everything else (with a tab focused) |
