# Security policy

Please report suspected vulnerabilities privately, using GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for a security problem.

Include what you found, how to reproduce it, and the version you tested. You
will get an acknowledgement, and a fix or a mitigation will be coordinated with
you before details are published.

Only the latest release receives security fixes.
